## Long description
LeanCart Store Credit solves one daily problem for WooCommerce store owners: "not being able to manage returns and loyalty balances".
Instead of hundreds of options and bloated code, it is a focused tool that works
right after installation.

### Why buy it?
- **Saves time:** Gives credit instead of cash for returns and loyalty programs
- **Minutes to set up:** Works with sensible defaults.
- **Secure:** WordPress CRUD API, nonce and capability checks, proper escaping.
- **Compatible:** WooCommerce 8+, HPOS, PHP 8.0+, WordPress 6.2+.
- **Supported:** 12 months of updates and support, 30-day money-back guarantee.

### Features
* Balance per user
* Credit use at checkout
* Automatic deduction
* Balance display in My Account

### Who is it for?
Stores with returns and loyalty processes
